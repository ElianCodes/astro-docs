[React Bricks](https://www.reactbricks.com/) is a visual headless CMS designed for React-based projects, providing visual editing, asset management, versioning, and flexible workflows. Combining React Bricks with Astro lets you easily deliver dynamic, editable content from a modern CMS.

## Installation

1. Bootstrap an Astro project with React Bricks:

```bash
npx create-reactbricks-app@latest
```

The CLI will help you set up an Astro project with TailwindCSS and prebuilt React Bricks components you can use.

2. If you already have an account, you can log in directly via the CLI, if not, register on [React Bricks](https://www.reactbricks.com/sign-up). Once you're logged in you can create a new project or choose an existing one.
